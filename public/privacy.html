隐私优先

访客只能发提醒，不能看到车主联系方式

二维码只包含匿名车辆 token。手机号、ShowDoc token、通知配置和完整绑定资料只由服务端处理。

访客能看到什么

  • 脱敏车牌，例如 `粤B***45`。
  • 可用通知按钮，例如 ShowDoc、短信、隐私号呼叫。
  • 通知发送结果和限流提示。

访客看不到什么

  • 车主手机号、微信号、ShowDoc webhook、ShowDoc token。
  • 完整车牌号和车主绑定配置。
  • 腾讯云密钥、短信模板参数、隐私号服务 token。

服务端如何保护数据

  • 手机号和 ShowDoc token 使用服务端密钥加密保存。
  • 访客 IP 只用于哈希限流，不在前端返回。
  • 通知接口对同一车辆和访客短时间重复提醒进行限制。
  • `/api/health` 只返回配置是否存在和缺失项名称，不返回任何密钥值。

演示模式说明

当前 GitHub Pages 默认启用浏览器 demo 模式。demo 数据只保存在当前浏览器的 localStorage， 不会真正发送 ShowDoc、短信或隐私号通知。接入 Cloudflare Worker 后，真实数据由 Worker 和 D1 处理。
